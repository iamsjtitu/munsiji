# Fonts bundled for PDF exports

`FreeSans.ttf` / `FreeSansBold.ttf` — GNU FreeFont (GPLv3 with font-embedding exception), https://savannah.gnu.org/projects/freefont/

Bundled because ReportLab's built-in Helvetica has no ₹ (U+20B9) glyph — it rendered as a black box in statements.
FreeSans also covers Devanagari, so Hindi ledger names print correctly.
